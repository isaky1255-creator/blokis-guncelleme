# Blokis canlı güncelleme paketleri

Blokis oyununun (App Store / Google Play) mağaza sürümü çıkarmadan dağıtılan web paketleri.
Oyun açılışta `surum.json` dosyasına bakar; daha yeni paket varsa indirir ve bir sonraki açılışta onunla başlar.

Paketler `blok-ustasi/tools/canli-guncelle.sh` ile üretilir. Elle düzenlemeyin.
